# CatUnlocker

Утилита для Windows, которая помогает **восстановить доступ к системным инструментам** после действий вирусов или ошибочных политик: снимает ограничения на диспетчер задач, редактор реестра, командную строку, панель управления и другие элементы.

Работает в двух режимах:

- **Обычная система** — графическое окно со списком найденных ограничений и галочками.
- **Среда восстановления (WinRE)** — консольный режим, который снимает ограничения напрямую в offline-реестре на диске `C:`.

Перед любыми изменениями создаётся **бэкап `.reg`**, чтобы можно было откатиться.

> ⚠️ Утилита предназначена для восстановления **своей** системы. Она не обходит пароли, не снимает ограничения на чужих/рабочих ПК и не скрывает свои действия.

---

## Возможности

- Сканирование ограничений в `HKLM` и `HKCU`.
- Список найденных ограничений с описанием и путём в реестре.
- Выборочное снятие: отмечаете галочками только то, что нужно.
- Автоматический бэкап `.reg` перед изменением.
- Работа в **WinRE**: загрузка offline-улья `SOFTWARE`, снятие ограничений, выгрузка улья.
- Один `.exe` — Python и `tkinter` внутри, на целевой машине **Python не нужен**.

### Что проверяется

| Ограничение | Ветка | Параметр |
|---|---|---|
| Диспетчер задач | `...\Policies\System` | `DisableTaskMgr` |
| Редактор реестра | `...\Policies\System` | `DisableRegistryTools` |
| Командная строка | `...\Policies\System` | `DisableCMD` |
| Панель управления | `...\Policies\Explorer` | `NoControlPanel` |
| Пункт «Выполнить» | `...\Policies\Explorer` | `NoRun` |
| Параметры папок | `...\Policies\Explorer` | `NoFolderOptions` |

Проверяются как `HKEY_LOCAL_MACHINE`, так и `HKEY_CURRENT_USER`.

## Требования

- Windows 10/11 (x64).
- Для **сборки**: Python 3.10+ и `pyinstaller`.
- Для **запуска**: ничего, кроме самого `.exe`.
- Для записи в `HKLM` — права администратора.

## Сборка

```powershell
git clone https://github.com/<username>/catunlocker.git
cd catunlocker

pip install pyinstaller
pyinstaller --onefile --name catunlocker ^
    --icon catunlocker.ico ^
    --add-data "catunlocker.ico;." ^
    catunlocker.py
```

Готовый файл: `dist\catunlocker.exe`.

> В PowerShell вместо `^` используйте обратный апостроф ``` ` ``` или пишите команду в одну строку.

## Использование

### Обычная система

1. Запустите `catunlocker.exe` **от имени администратора** (правой кнопкой → «Запуск от имени администратора»).
2. В окне появится список найденных ограничений.
3. Кликните по строкам, которые нужно снять (они подсветятся зелёным).
4. Нажмите **«Снять выбранное»**.
5. Утилита создаст `catunlocker_backup_*.reg` и изменит значения на `0`.

### Среда восстановления (WinRE)

1. Загрузитесь в WinRE: `Shift` + «Перезагрузка» → Поиск и устранение неисправностей → Дополнительные параметры → **Командная строка**.
2. Определите букву диска Windows:
   ```cmd
   diskpart
   list volume
   exit
   ```
3. Запустите `catunlocker.exe` с флешки:
   ```cmd
   E:\catunlocker.exe
   ```
4. Введите букву диска (например, `C`).
5. Выберите номера ограничений для снятия.
6. Утилита загрузит offline-улей, снимет выбранное, сделает бэкап и выгрузит улей.
7. Перезагрузитесь в обычную систему.

> Буква диска в WinRE может отличаться от обычной системы — всегда проверяйте через `diskpart → list volume`.

## Откат изменений

Перед каждым снятием создаётся `.reg`-бэкап рядом с `.exe` (или в текущей папке). Чтобы вернуть ограничения:

```cmd
reg import catunlocker_backup_YYYYMMDD_HHMMSS.reg
```

## Ограничения и известные нюансы

- В **WinRE** графический интерфейс (`tkinter`) недоступен — утилита автоматически переключается в консольный режим (определение по `MiniNT`/`PE`/`SystemDrive=X:`).
- В **WinRE** снимаются ограничения только в `HKLM` (системные). Ограничения `HKCU` требуют загрузки `NTUSER.DAT` — пока не поддерживается.
- `reg load` может вернуть «I/O operation failed», если неверна буква диска или улей занят.
- `pyinstaller --onefile` распаковывается во временную папку при каждом запуске — в WinRE на флешке это может занять 10–20 секунд. Для быстрого старта используйте `--onedir`.
- `gpedit.msc` может отсутствовать в Windows Home — это не ограничение реестра, а отсутствие компонента. Снятие ключей это не исправит.
